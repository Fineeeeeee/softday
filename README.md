# Softday

Softday 是一个温和、克制的个人安排助手。它帮助用户记下想法、安排今天，并在现实发生变化时重新安放事情。

## 项目概览

Softday 解决的是个人计划工具容易把生活变成打卡、评分和逾期管理的问题。核心流程是：记下一件事 → 确认如何安排 → 开始或完成 → 情况变化时重新安放 → 在回顾中查看事实记录。

系统采用 React Native、Expo、TypeScript 和本地版本化快照；提醒使用设备本地能力，计划数据不依赖云端。模型能力只在用户主动触发时参与整理、拆解、重排或回顾建议，结果必须经过本地校验和用户确认，不能直接修改计划或执行外部操作。

项目不包含登录、云同步、远程推送、第三方日历或远程数据分析，也不宣称用户规模、留存、效率提升或其他业务效果。当前验证重点是领域规则、数据迁移、本地恢复和移动端交互。

## 当前能力

- 一次输入一段自然语言，智能整理为最多 8 件带原文依据的事项，再轻量确认
- 可识别“每天、工作日、每周几”，完成后只生成下一次；近期同名事项反复完成时，会在本地给一句可忽略的重复建议，最终仍由用户确认
- 重复事项可以只跳过今天、暂停到几天后，或只修改当前这一次；后续规则不会被意外改掉
- 首页只展示一个“当前焦点”，其余事项按需展开
- 当前焦点采用轻纸片与时段光晕；未开始时可点圆圈或右滑完成，开始后主按钮切换为完成
- 专注状态保存在本地快照中，切后台或重启后仍会回到同一件事
- 完成事项会记录实际完成时间；“回顾”支持最近 28 天、整年和自选日期区间，并用安静的全年日期密度图帮助找回记忆
- 回顾会把近期重复出现的同名事项收成简短轨迹，只展示次数与常见时段，不使用连续打卡或完成率
- 可记下“还没开始 / 做到一半 / 在等别人”的任务断点，下次直接从下一小步继续
- 今日容量和安排建议
- 动态重排、冲突检查和截止提醒
- 剩余时间和临时变化的快捷重排
- 跨天事项逐项安放
- 复杂事情可先做 5 分钟或拆成下一小步
- 未完成事项可选择明天、周末、有空时或暂时收起
- 到合适时间只温和找回一件事，也可继续延后
- 想做清单、搜索、编辑和分组
- 一次选择多个文本文件，智能找出带原文出处的待确认事项
- 今日收尾、历史记录和节奏偏好
- 设备本地持久化与备份文本恢复
- 有明确截止日期事项的本地系统提醒

当前不包含登录、云同步、远程推送、地图和第三方日历。

应用会在本地记录完成、推迟和拆解等行为的少量上下文，并按最近 28 个活跃日每天刷新一次近期节奏。相同事项在 28 天内完成至少 3 次后，记录页才可能轻声建议设为重复；样本不足时不做判断。手动选择的专注时段、重复规则和夜间偏好始终优先。近期节奏只微调待确认的安排建议，不会自动改动已有事项，也不会发送给智能服务。

今天页只根据本地早上、白天和晚上的时间改变顶部环境光，不使用场景插画，也不需要定位或联网。

智能服务使用 OpenAI-compatible Chat Completions JSON 格式，只在用户点击“整理一下”“重新看看”“变简单一点”、主动导入文件，或带备注记录任务断点时调用。API 地址按基础地址保存，请求时自动添加 `/chat/completions`；已经包含该路径时不会重复添加。普通记录一次模型请求最多返回 8 件待确认事项，每件都必须带输入中逐字存在的原文片段；独立行动会分开，同一复杂目标只留下一个可开始的下一步。模型只能在原文明确表达重复意图时提出重复规则。它也可生成符合剩余时间的重排建议、2 到 4 个具体步骤、带原文出处的文件事项，或当前任务的断点下一步；不能替用户标记完成、改变任务日期或执行外部操作。应用在本地校验并去重后，仍需用户确认才会写入数据。

文件导入首版一次最多选择 6 个文本文件，支持 TXT、Markdown、CSV、JSON、LOG 和 YAML；单个文件不超过 256 KB，合计最多读取 30,000 字。PDF、图片和 Office 文件会留在本地并说明暂不支持。文件原文只用于本次用户主动发起的提取，不写入任务、备份或使用习惯；最终只保留用户确认的标题、时间信息、文件名和不超过 160 字的原文片段。

API 地址和模型名称保存在本地设置中；API Key 只保存在设备安全存储，不会进入备份、日志或应用配置。只允许 HTTPS 公网端点，不会向本机、局域网或私有 IP 地址发请求。

## 运行

```powershell
npm install
npm run start -- --port 8092
```

Android 本地通知需要 development build，不能使用 Expo Go 验证：

```powershell
npx expo run:android --device
```

应用不会自动申请通知权限。用户在“我的”中开启后，只为有明确截止日期且未完成的事项安排本地通知；不注册远程推送 Token。

## 验证

```powershell
npm run test:domain
npm run typecheck
npx expo install --check
```

领域规则位于 `src/domain/`，相邻的 `*.test.ts` 覆盖解析、排程、重排、跨天和备份逻辑。

用户计划、想做、偏好和历史记录保存在一个版本化本地快照中。旧版本的分散数据只在首次迁移时读取，迁移不会删除旧数据；API Key 始终独立保存在系统安全存储中。
